# Northbridge CivicCMS: platform overview

> Synthetic data. Northbridge CivicCMS is a fictional product.

## Hosted platform
Northbridge CivicCMS is our content management system built for government websites. It is provided as a hosted service (software as a service): the license, hosting, security updates and new features are included in one annual fee. Clients never need to install or patch software.

## Designed for non-technical staff
Content editors work in a browser with a visual editor. They can add pages, images, documents and links without HTML knowledge. Layouts are built from pre-designed, accessible components (text, image, accordion, tabs, cards, call-to-action buttons, embedded maps and videos), so pages stay consistent with the site design.

## Users, roles and permissions
- Unlimited administrator and editor accounts at no extra cost.
- Role-based permissions: administrators define which department or section each editor can edit.
- Approval workflows: an editor's changes can require approval from a department lead or the communications team before going live, with email notifications at each step.
- Staff sign in with single sign-on (SAML 2.0 or OpenID Connect) through the city's identity provider, for example Microsoft Entra ID, with multi-factor authentication enforced by that provider.

## Audit and recovery
Every change is versioned. Editors can compare revisions and restore any previous version of a page. An audit log records who changed what and when, and is kept for 3 years.

## Product updates
New CivicCMS features are released to all clients four times a year at no additional cost, after testing on a staging environment.
