# Northbridge CivicCMS: content publishing features

> Synthetic data.

## Scheduling
Any page, news item, alert or homepage highlight can be scheduled to publish and to unpublish at a set date and time. Scheduled items appear in a publishing calendar so the communications team can see what goes live and what expires.

## Front-end (live) editing
Logged-in editors can switch to live editing mode and add, edit and move content blocks directly on the public page they are viewing, with a preview before publishing. Drag-and-drop reordering is available for content blocks and navigation menus.

## Hiding and deleting pages
- Pages can be hidden (unpublished) without being deleted, and restored later.
- Pages can be permanently deleted by users with the delete permission.
- Hidden or deleted pages are removed from the site search index and from the XML sitemap immediately, and return an HTTP 404 or 410 status, so search engines drop them from their results. Editors can also add a "noindex" setting to any page.

## Friendly URLs and redirects
Editors can create short vanity URLs (for example /trash or /permits) and organize them in a redirect manager, with a record of who created each redirect. The system warns about duplicate or conflicting URLs. Changing a page's address automatically creates a redirect from the old address.

## Content quality tools
Built-in broken-link checker, an accessibility checker that flags missing alternative text, empty headings and low color contrast before publishing, and a readability score for each page.
