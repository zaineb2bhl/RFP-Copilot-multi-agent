# Methodology: Security and data protection

> Synthetic data.

## Information security management
Our ISO/IEC 27001:2022 certified information security management system covers all delivery and support activities. Security is integrated into every sprint through threat modelling, secure coding guidelines (OWASP ASVS level 2), dependency scanning and static code analysis in the CI pipeline.

## Data protection
We act as a data processor under a written data processing agreement. We support clients with Data Protection Impact Assessments, apply data minimisation and pseudonymisation where possible, and host personal data in EU or UK data centres only.

## Technical controls
- Encryption at rest (AES-256) and in transit (TLS 1.2 or higher).
- Multi-factor authentication for all administrative access, role-based access control and least privilege.
- Annual independent penetration testing, plus testing before every major release; critical findings fixed before go-live.
- Security incidents notified to the client within 24 hours.
