# Methodology: Agile delivery and project governance

> Synthetic data.

## Delivery approach
Northbridge Digital delivers projects with Scrum in 2-week sprints, inside a phased governance framework: discovery (4 to 6 weeks), alpha, beta and live. Each sprint ends with a demo to the client's product owner and a retrospective.

## Governance
- A monthly steering committee with the client's sponsor reviews progress, budget, risks and decisions.
- A weekly project report covers burn-up, risks and issues, dependencies and change requests.
- A RAID log (risks, assumptions, issues, dependencies) is shared with the client in real time.
- Change requests follow a documented impact analysis and approval process.

## Tooling
Jira for backlog management, Confluence for documentation, and Azure DevOps or GitHub for source control and CI/CD. The client has full access to all tools and keeps ownership of the code and documentation.
